# GitHub Pages checker setup

Put these files into your repository as follows:

```text
violating_ripe_probes/
├── .github/
│   └── workflows/
│       └── update_data.yml
└── interactive_checker/
    ├── fetch_data.py
    ├── requirements.txt
    ├── root_locations.csv          # keep your existing file
    ├── data/                       # generated by the workflow
    └── site/
        ├── index.html
        ├── app.js
        ├── styles.css
        └── data/                   # generated by fetch_data.py
```

## One-time GitHub setting

In the repository, open **Settings → Pages** and set **Source** to **GitHub Actions**.

Also make sure **Settings → Actions → General → Workflow permissions** allows **Read and write permissions**.

## Test

Open **Actions → Update RIPE Atlas data and deploy checker → Run workflow**, choose a slot, and run it.

After a successful run, the workflow will:

1. fetch the latest RIPE Atlas snapshot,
2. combine the day's available 06/12/18 snapshots,
3. precompute SOI outcomes,
4. write compact static JSON under `interactive_checker/site/data/`,
5. commit generated data back to the repo, and
6. deploy `interactive_checker/site/` to GitHub Pages.
